# مدرسه‌یار دانش‌آموز — نسخه ۱.۱۲.۰

این مخزن شامل پوسته Android و فایل‌های یکپارچه‌سازی پنل دانش‌آموز است. نسخه ۱.۱۲ روی سرعت همگام‌سازی، نمایش تاریخ آخرین بروزرسانی، جداسازی امن داده‌های حساب‌ها، خروج کامل و انتشار پایدار APK تمرکز دارد و امکانات نسخه‌های قبل را حفظ می‌کند.

## تغییرات نسخه ۱.۱۲
- داشبورد زمان دقیق «آخرین بروزرسانی موفق» را با تاریخ شمسی و ساعت نمایش می‌دهد و این مقدار برای هر دانش‌آموز جداگانه روی گوشی ذخیره می‌شود.
- دکمه به‌روزرسانی دیگر برای اجرا وارد صفحه «بیشتر» نمی‌شود و Sync مستقیماً از داشبورد انجام می‌شود.
- داشبورد و فهرست نتایج به‌صورت موازی دریافت می‌شوند و برای درخواست‌های Sync مهلت پاسخ محدود در نظر گرفته شده است.
- جزئیات کارنامه فقط زمانی دوباره دانلود می‌شوند که `resultRevision` یا `resultUpdatedAt` تغییر کرده باشد یا نسخه محلی موجود نباشد؛ کارنامه‌های بدون تغییر دوباره دریافت نمی‌شوند.
- هنگام Sync، مرحله واقعی عملیات در رابط نمایش داده می‌شود و اطلاعات اصلی قبل از جزئیات غیرضروری در دسترس قرار می‌گیرند.
- هنگام ورود حساب دانش‌آموز متفاوت، Cache، آزمون‌های دانلودشده، Draftها، صف ارسال و پروفایل حساب قبلی پاک می‌شوند؛ ورود مجدد همان حساب داده‌های آفلاین خودش را حفظ می‌کند.
- Token ورود فقط پس از دریافت موفق داشبورد ذخیره می‌شود تا خطای بین Login و Dashboard باعث نمایش Cache حساب قبلی نشود.
- Logout در حالت آنلاین ابتدا دستگاه را از Push حساب خارج و Session سرور را revoke می‌کند؛ خروج محلی حتی در قطع اینترنت فوری باقی می‌ماند.
- Android تغییر FCM Token را از `FirebaseMessagingService` دریافت و در اولین فرصت دوباره به حساب فعال Bind می‌کند.
- نسخه Android و endpoint نسخه سرور هر دو روی `1.12.0 / versionCode 12` تنظیم شده‌اند.
- GitHub Actions در صورت وجود Secretهای امضای Release، APK امضاشده می‌سازد؛ در غیر این صورت فقط Debug APK تولید می‌شود. فایل‌های Firebase و Keystore نیز در `.gitignore` قرار گرفته‌اند.

## استقرار نسخه ۱.۱۲
1. از فایل‌های فعلی هاست، مخصوصاً `app/student/app.js` و `server.mjs`، پشتیبان بگیر.
2. فایل `server-integration/INSTALL-ROOT/student/app.js` را روی `app/student/app.js` هاست جایگزین کن.
3. تغییرات `server-integration/INSTALL-ROOT/server.mjs` را نیز روی سورس اصلی سرور اعمال کن تا نسخه Android و API نسخه هماهنگ شوند. این پوشه Overlay است و جایگزین کل بک‌اند نیست.
4. برای Push، فایل `shared/mobile-push.mjs` باید در سورس اصلی سرور موجود و تنظیمات Firebase سرور فعال باشد.
5. برای ساخت Release قابل Update، Secretهای `ANDROID_RELEASE_KEYSTORE_BASE64`، `ANDROID_RELEASE_KEYSTORE_PASSWORD`، `ANDROID_RELEASE_KEY_ALIAS` و `ANDROID_RELEASE_KEY_PASSWORD` را در GitHub تنظیم کن.
6. پس از استقرار وب و سرور، APK نسخه ۱.۱۲ را با همان کلید امضای نسخه قبلی نصب/Update کن.

## تغییرات نسخه ۱.۱۰
- منوی پایین «نمرات» به صفحه واقعی نمرات متصل است و دیگر پنجره چت معلم را باز نمی‌کند.
- هنگام ارسال آزمون، پنجره پیشرفت با درصد، نوار قابل‌اندازه‌گیری و وضعیت ثبت سرور نمایش داده می‌شود.
- درخواست ارسال آزمون از طریق رویدادهای واقعی بارگذاری XHR در WebView پیشرفت را گزارش می‌کند؛ هنگام پردازش سرور درصد روی وضعیت انتظار می‌ماند تا تأیید واقعی برسد.
- ارسال فوری فقط آزمون جاری را می‌فرستد و منتظر ارسال آزمون‌های قدیمی در صف یا دریافت دوباره داشبورد و نمرات نمی‌ماند. به‌روزرسانی داشبورد و کارنامه پس از نمایش رسید در پس‌زمینه انجام می‌شود.
- از لمس تکراری دکمه ارسال جلوگیری می‌شود و در صورت خطای شبکه، پاسخ‌ها در صف محلی باقی می‌مانند.
- نسخه APK به `1.11.0` و `versionCode 11` ارتقا یافته است؛ پس از همگام‌سازی، گزارش تغییرات و اعلان فعال‌شدن آزمون‌های جدید نمایش داده می‌شود.

## تغییرات نسخه ۱.۹
- صفحه نمرات ابتدا از IndexedDB روی گوشی خوانده می‌شود و هم‌زمان اطلاعات تازه در پس‌زمینه دریافت می‌شوند.
- دکمه «به‌روزرسانی» داشبورد، فهرست نمرات و جزئیات آزمون‌ها را روی دستگاه ذخیره می‌کند.
- جزئیات کارنامه تفصیلی در دفعات بعد از حافظه محلی باز می‌شود؛ در صورت اتصال، نسخه جدید سرور نیز بررسی و ذخیره می‌شود.
- اگر حساب دانش‌آموز دیگری روی همان گوشی وارد شود، فهرست و جزئیات نمرات ذخیره‌شده حساب قبلی پاک می‌شود تا اطلاعات دانش‌آموزان با هم اشتباه نشوند.

## استقرار اصلاحات نسخه ۱.۱۰
**این نسخه دو بخش دارد:** اصلاح پنل روی هاست و اصلاح پوسته اندروید. ساخت APK به‌تنهایی کد ارسال آزمون در هاست را تغییر نمی‌دهد.

1. از فایل فعلی هاست `app/student/app.js` نسخه پشتیبان بگیر.
2. فایل `server-integration/INSTALL-ROOT/student/app.js` را با `app/student/app.js` روی هاست جایگزین کن.
3. برای رفع مسیر منوی پایین، APK جدید را از همین سورس بساز و نصب کن؛ فایل‌های `app/src/main/assets/girl-dashboard.js` و `girl-sections.css` در APK قرار دارند.
4. در این اصلاح نیازی به تغییر `server.mjs` یا دیتابیس نیست.

## نصب اصلاح عملکرد کارنامه
**نکته مهم:** اپ اندروید صفحه پنل را از `https://scooljavanrood.ir/app/student/` بارگذاری می‌کند؛ بنابراین ساخت APK به‌تنهایی کد صفحه نمرات را روی هاست تغییر نمی‌دهد.

1. از فایل فعلی هاست `app/student/app.js` یک نسخه پشتیبان بگیر.
2. فایل `server-integration/INSTALL-ROOT/student/app.js` همین بسته را با فایل `app/student/app.js` هاست جایگزین کن.
3. نیازی به تغییر `server.mjs`، دیتابیس یا تنظیمات API نیست.
4. یک بار با اینترنت وارد برنامه شو، از خانه «به‌روزرسانی» را بزن و صبر کن تا وضعیت «ذخیره شد» نمایش داده شود.
5. صفحه نمرات و تحلیل یک آزمون را باز کن. سپس اینترنت را قطع و همان بخش‌ها را دوباره باز کن تا نمایش محلی را آزمایش کنی.

## ساخت APK
در GitHub Actions، گردش‌کار `Build Android APK` را اجرا کن. اگر Secretهای امضای Release کامل باشند خروجی امضاشده Release ساخته می‌شود؛ در غیر این صورت Workflow فقط Debug APK تولید می‌کند. برای نصب روی نسخه قبلی، امضای APK باید دقیقاً با نسخه نصب‌شده یکسان باشد.

## آزمون‌های خودکار
در پوشه ریشه اجرا کن:

```bash
node --check server-integration/INSTALL-ROOT/student/app.js
node --check server-integration/INSTALL-ROOT/server.mjs
node --test tests/*.test.mjs
```
