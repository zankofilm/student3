# تغییرات مدرسه‌یار دانش‌آموز ۱.۱۲.۰

- `versionCode 12` / `versionName 1.12.0`.
- نمایش تاریخ و ساعت شمسی آخرین Sync موفق در داشبورد، به‌صورت جدا برای هر دانش‌آموز.
- حذف مسیر رفت‌وبرگشت به صفحه «بیشتر» از دکمه بروزرسانی.
- Sync موازی داشبورد و نتایج، Timeout محدود و نمایش مرحله واقعی عملیات.
- دریافت جزئیات کارنامه فقط برای نتیجه جدید یا تغییرکرده بر اساس `resultRevision` و `resultUpdatedAt`.
- پاک‌سازی همه Storeهای دانش‌آموز قبلی هنگام تعویض حساب و افزودن شناسه دانش‌آموز به Queueهای جدید.
- جلوگیری از ذخیره Token ورود تا قبل از دریافت موفق Dashboard.
- Logout آنلاین شامل Unregister دستگاه از Push و Revoke Session سرور.
- پشتیبانی از Rotation توکن FCM در Android.
- هماهنگ‌سازی نسخه اعلامی سرور با APK.
- پشتیبانی از Release Signing در GitHub Actions فقط از طریق Secrets و افزودن `.gitignore` برای مواد حساس.
- تست‌های اختصاصی V1.12 برای Sync، حساب‌ها، Push، نسخه و Release Signing.
